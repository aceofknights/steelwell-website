Hex Math

Change one multiplication factor, claim a product, and connect four hexes in a two-player game.

Overview

A local two-player multiplication strategy game. Players change one factor at a time; the matching product is claimed automatically when it is available.

Key features

  • Choose factors from 1 through 12.
  • Alternate turns on a shuffled board of multiplication products.
  • Connect four owned hexes along a board axis to win.
  • Track wins during the current page session and start a new board.

How to use

  1. Share the screen with another player.
  2. Select a different value in either factor panel; the game claims the matching unclaimed product.
  3. Use New game or Play again to start another board.
