ChrisWellsDev Website

A static developer portfolio bringing together interactive tools, games, software, and coursework.

Overview

This website brings together browser applications, software project notes, and coursework in a shared developer dashboard design. Static HTML keeps its core navigation and project links available without JavaScript.

Key features

  • A categorized project catalog and dedicated Tools & Games page.
  • Consistent showcase layouts, cards, and responsive navigation.
  • Direct links to the original interactive tools.
  • Static hosting through GitHub Pages.

How it works

A shared CSS design system and a project manifest support checked-in HTML showcases. Core links are available without JavaScript, while the browser tools keep their own interaction code.

Project notes

No runtime framework, backend, or build step is required to serve the checked-in pages.
