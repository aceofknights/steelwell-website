Sort the Numbers

Select shuffled numbers from one to five in ascending order.

Overview

A short sequence game: find five shuffled numbers and select them in ascending order. Each correct selection advances the sequence; a mistake starts a fresh round.

Key features

  • Shuffle five numbered cards at the start of each round.
  • Mark correct selections as you progress.
  • Restart automatically after success or an incorrect selection.
  • Use Tab to reach the cards and Enter or Space to select them.

How it works

The five shuffled cards share a single expected-number sequence. Native buttons let pointer and keyboard input use the same selection and reset rules.

How to use

  1. Select 1, then 2, 3, 4, and 5.
  2. Dismiss the result message to continue with a freshly shuffled round.

Project notes

Mouse, touch, and keyboard use the same buttons. Existing browser alerts announce the result before a new round starts.
